# 麻将计分器

一款用于线下牌局的**微信小程序**：快速开局、按回合记分、查看排名，并支持生成简易战绩海报与分享给好友。

## 功能概览

- **开局设置**：支持 2～8 名玩家（预设人数可切换），编辑昵称，每位玩家有固定序号的可爱头像。
- **记分板**：选择当前玩家，快捷加减分或输入自定义分数；支持多回合、重置本局、结束本局。
- **结果页**：本局排名与回合明细；Canvas 生成战绩海报，可预览或保存到相册。
- **我的**：历史战绩列表；可选登录（云开发 + 手机号能力，视后台配置而定）。
- **分享**：支持转发给好友与分享到朋友圈（具体能力以微信客户端与审核策略为准）。

## 技术栈

- 微信小程序原生（WXML / WXSS / JS）
- 微信云开发：`wx.cloud.init`，云函数目录 `cloudfunctions/`（示例含 `login`）
- 本地存储：当前对局与历史记录使用 `wx.setStorageSync`（见下方说明）

## 本地开发与预览

1. 安装并打开 [微信开发者工具](https://developers.weixin.qq.com/miniprogram/dev/devtools/download.html)。
2. 选择「导入项目」，目录指向本仓库根目录。
3. 在 `project.config.json` 中将 **AppID** 改为你自己的小程序 AppID（测试可使用测试号）。
4. 若使用云开发：
   - 在微信公众平台开通云开发，创建环境；
   - 在 `app.js` 中将 `wx.cloud.init` 的 `env` 改为你的云环境 ID；
   - 在开发者工具中上传并部署 `cloudfunctions/login`（依赖与 Node 版本按工具提示配置）。

不使用云开发时，仅影响登录相关能力；**记分、历史、海报等仍可在本地正常使用**。

## 本地存储说明（开发者）

| 键名 | 用途 |
|------|------|
| `mj_current_game` | 当前进行中的对局数据 |
| `mj_score_history` | 已结束对局历史（条数上限在代码中限制） |
| `mj_user` | 登录用户信息缓存 |

清理开发者工具缓存或卸载小程序会清空上述数据。
