# 各地麻将规则速查手册

> 本文档供微信AI知识库使用，帮助用户快速了解全国各地主流麻将玩法的核心规则差异。

---

## 一、四川麻将 —— 血流成河

### 核心特点
- **定缺**：开局每人选定一门缺的花色（万/筒/条之一），胡牌前不能持有该花色
- **血流**：有人胡牌后牌局不结束，已胡玩家继续摸打
- **血战**：直到只剩一家未胡或牌墙摸完
- **不能吃**：只能碰和杠，不能吃上家的牌

### 胡牌规则
- 必须缺一门才能胡
- 胡牌后继续参与摸打（血流特色）
- 牌墙结束后查叫（惩罚未听牌者）和查花猪（惩罚仍持有定缺花色者）

### 计分规则
- 基础胡牌 + 番型倍数
- 杠牌有额外分数（刮风下雨规则）
- 自摸三家付，放炮放炮者付
- 查叫查花猪的罚分

### 常见术语
| 术语 | 解释 |
|---|---|
| 定缺 | 开局选一门不要的花色 |
| 刮风 | 明杠得分 |
| 下雨 | 暗杠得分 |
| 查叫 | 结束后未听牌者赔分 |
| 查花猪 | 结束后仍持定缺花色者赔分 |
| 金钩钓 | 碰碰胡到只剩一张单吊 |
| 带幺 | 每组面子都带1或9 |

## 二、武汉麻将 —— 红中癞子杠

### 核心特点
- **红中万能**：红中可代替任意牌作为癞子使用
- **开口要求**：必须先吃/碰/杠（开口）后才能胡牌
- **不能吃**：部分玩法禁止吃牌，只能碰杠
- **前皮后癞**：翻出的癞子牌的前一张为皮子，有特殊规则

### 胡牌规则
- 必须先开口（吃碰杠过至少一次）
- 硬胡（不用癞子）比软胡（用癞子）分数高
- 胡牌方式：自摸、接炮（放炮）

### 计分规则
- 基础胡牌分 + 番型加分
- 硬胡分数翻倍
- 杠牌有杠分
- 抢杠、杠开额外加分

### 常见术语
| 术语 | 解释 |
|---|---|
| 癞子 | 可代替任意牌的特殊牌（通常红中） |
| 开口 | 吃过/碰过/杠过至少一次 |
| 硬胡 | 不用癞子胡牌 |
| 软胡 | 用了癞子胡牌 |
| 皮子 | 癞子牌的前一张 |
| 金顶 | 达到最高番数上限 |
| 包胡 | 特殊情况下某人承担全部输分 |

## 三、杭州麻将

### 核心特点
- **财神系统**：开局翻出一张牌，下一张为财神，可代替部分牌
- **爆头机制**：财神与将牌的关系影响计分
- **不能吃**：和四川麻将一样只能碰杠
- **可放炮**：允许点炮胡牌

### 胡牌规则
- 满足基础胡牌结构
- 财神的使用需符合当地规则限制
- 爆头有额外加分

### 计分规则
- 基础胡牌 + 番型叠加
- 自摸、放炮、杠分分别计算
- 财神飘（多个财神）有额外倍数

### 常见术语
| 术语 | 解释 |
|---|---|
| 财神 | 可代替牌的特殊牌 |
| 爆头 | 财神和将牌的特殊关系 |
| 杠开 | 杠后补牌直接胡 |
| 飘财 | 多个财神的特殊用法 |
| 七对 | 七个对子的特殊牌型 |
| 豪华七对 | 含杠的七对 |

## 四、广东麻将（广东推倒胡）

### 核心特点
- **鸡胡可胡**：最低级的鸡胡也能胡牌（不需要番数门槛）
- **可吃可碰**：可以吃上家、碰任意家、杠任意家
- **可放炮**：允许点炮胡牌
- **马牌**：胡牌后翻马决定额外倍数

### 胡牌规则
- 满足基础胡牌结构即可胡
- 鸡胡（无番）也可胡牌
- 自摸三家付，放炮放炮者付

### 计分规则
- 番型叠加：鸡胡(0番) < 平胡(1番) < 碰碰胡(2番) < 混一色(3番) < 清一色(6番) < 十三幺(13番)
- 马牌翻倍机制
- 抢杠、杠开额外加分

### 常见术语
| 术语 | 解释 |
|---|---|
| 鸡胡 | 无番基础胡 |
| 平胡 | 全顺子无字牌 |
| 马牌 | 胡后翻的额外倍数牌 |
| 中马 | 翻到马牌得分 |
| 自摸 | 自己摸到胡牌 |
| 放炮 | 打出牌被别人胡 |
| 十三幺 | 广东麻将中极高分牌型 |

## 五、国标麻将

### 核心特点
- **81个番种**：最丰富的牌型体系
- **8番起胡**：必须凑够至少8番才能胡牌
- **不重复计番**：每个番种只计一次，选择最高组合
- **标准规则**：全国比赛通用规则

### 胡牌规则
- 必须达到最低番数门槛（通常8番）
- 番种不能重复计算（不重复原则）
- 自摸加1番

## 六、日本麻将（立直麻将）

### 核心特点
- **立直**：听牌后宣布立直，加1番但不能换牌
- **一番缚**：必须有至少1番才能胡牌
- **振听**：自己打过的牌不能胡（即使后来听那张）
- **宝牌**：开牌时指示的下一张为宝牌，每张加1番（但不计入起胡番数）

### 胡牌规则
- 必须有至少1番（宝牌不计入起胡番数）
- 振听状态下不能胡别人打出的牌（只能自摸）
- 立直后不能换牌
- 流局（牌墙摸完无人胡）听牌者得分

## 八、选玩法的建议

### 新手入门推荐
1. **广东麻将**：规则最简单，鸡胡也能胡，适合零基础
2. **杭州麻将**：节奏轻快，番型清楚

### 进阶挑战
3. **四川血流**：策略性强，需要管理花色
4. **武汉红中**：癞子系统需要适应

### 高手之路
5. **日本麻将**：防守策略要求高
6. **国标麻将**：81种番种需要熟悉

## 九、常见问题 FAQ

**Q: 清一色在所有玩法中都有吗？**
A: 几乎所有麻将玩法都包含清一色，但番数不同。广东约6番，国标24番，日本6番。

**Q: 哪个玩法最刺激？**
A: 四川血流最刺激，因为胡牌后还能继续打，一局可能多次结算。

**Q: 癞子和财神有什么区别？**
A: 本质相同，都是可代替其他牌的特殊牌。武汉叫癞子，杭州叫财神。

**Q: 为什么有的玩法不能吃？**
A: 不能吃牌的玩法更依赖手牌管理和防守策略，增加了技术含量。

**Q: 各地麻将胡牌基本结构一样吗？**
A: 大部分是四面子+一对将。但七对（七个对子）和十三幺（十三种幺九各一+一对）是例外。
