## 一、基础胡牌结构

无论哪种地方玩法，麻将胡牌的基础结构都是：**四组面子 + 一对将牌（雀头）**，共14张。

- **面子**可以是顺子（三张连续同花色）或刻子（三张相同牌）
- **将牌（雀头）**是一对相同的牌
- 少数特殊牌型（如七对、十三幺）不遵循此结构

## 二、常见牌型详解

### 1. 平和（平胡）
- **定义**：全部由顺子组成，将牌不是字牌，且听牌时两面听
- **判定**：四个顺子 + 一对非字牌将，无刻子
- **番数**：通常1番（基础牌型）
- **出现玩法**：几乎所有麻将玩法

### 2. 对对胡（碰碰胡）
- **定义**：全部由刻子（或杠）组成，没有顺子
- **判定**：四个刻子 + 一对将
- **番数**：通常2-4番
- **出现玩法**：所有玩法
- **典型牌例**：碰碰胡 + 红中是常见高分组合（武汉麻将）

### 3. 清一色
- **定义**：全部牌为同一种花色（万、筒、条中的一种），不含字牌
- **判定**：14张牌全部属于万/筒/条中同一花色
- **番数**：通常6-8番，部分地区更高（四川血流中为高番方向）
- **出现玩法**：所有麻将玩法
- **注意**：部分玩法中清一色要求不含字牌，部分允许含风箭（需确认当地规则）

### 4. 混一色
- **定义**：一种花色 + 字牌组成
- **判定**：所有牌为同一花色 + 任意风牌和箭牌
- **番数**：通常3-4番
- **出现玩法**：绝大多数麻将玩法
- **说明**：比清一色容易做，因为字牌人人都会打出

### 5. 七对（七小对）
- **定义**：七个对子，共14张，全部是成对的牌
- **判定**：手中14张牌组成7对，无碰无杠
- **番数**：通常4-6番
- **出现玩法**：几乎所有麻将玩法
- **特殊变体**：
  - **豪华七对**：七对中有一个杠（四张相同牌算两对）
  - **清七对**：清一色的七对，番数极高
  - **龙七对**：四川麻将中带杠的七对

### 6. 十三幺（十三不靠/国士无双）
- **定义**：十三种幺九牌各一张，再加其中任意一张组成对子
- **判定**：1万9万、1筒9筒、1条9条、东南西北、白发中，共13种各一张，再加任意一张配对
- **番数**：通常88番（国标）/ 满贯（日本）/ 最高番型
- **出现玩法**：国标麻将、日本麻将、部分地方玩法
- **难度**：极难做成，是最罕见的牌型之一

### 7. 大三元
- **定义**：中、发、白三组箭牌都凑成刻子（或杠）
- **判定**：红中刻子 + 发财刻子 + 白板刻子，再加一组面子 + 一对将
- **番数**：通常64-88番
- **出现玩法**：国标麻将、日本麻将、广东麻将等

### 8. 小三元
- **定义**：中、发、白中两组为刻子，一组为将牌
- **判定**：箭牌两组刻子 + 一组对子（将牌），加两组面子
- **番数**：通常48-64番
- **出现玩法**：同上

### 9. 大四喜
- **定义**：东、南、西、北四组风牌都凑成刻子（或杠）
- **判定**：东南西北各成刻子 + 一对将
- **番数**：通常88番
- **出现玩法**：国标麻将、日本麻将等
- **难度**：极难，仅次于十三幺

### 10. 小四喜
- **定义**：东、南、西、北中三组为刻子，一组为将牌
- **判定**：风牌三组刻子 + 一组对子（将牌），加一组面子
- **番数**：通常64番

### 11. 字一色
- **定义**：全部由字牌（风牌 + 箭牌）组成
- **判定**：14张全部为东南西北白发中
- **番数**：通常64-88番
- **说明**：极罕见牌型

### 12. 绿一色
- **定义**：全部由纯绿色的牌组成（条子2/3/4/6/8 + 发财）
- **判定**：仅使用条子中的2、3、4、6、8和发财
- **番数**：通常88番（日本麻将满贯以上）
- **出现玩法**：日本麻将、国标麻将

### 13. 九莲宝灯
- **定义**：清一色 + 1和9各三张、2到8各一张的听牌形态
- **判定**：同一花色中，1和9各三张、2到8各一张，听所有九张牌
- **番数**：通常88番
- **出现玩法**：日本麻将、国标麻将

### 14. 杠上开花（杠开）
- **定义**：杠牌后补牌直接胡牌
- **判定**：杠牌 → 从牌墙末尾补牌 → 这张补牌正好完成胡牌
- **番数**：通常加2-4番
- **出现玩法**：几乎所有玩法
- **常见场景**：杭州麻将中杠开是重要加分点

### 15. 抢杠胡
- **定义**：别人加杠（明杠升级）时，你恰好可以胡那张牌
- **判定**：对手把碰的牌加杠 → 你正好听那张牌 → 可以抢杠
- **番数**：通常加2-4番

### 16. 海底捞月
- **定义**：牌墙摸到最后一张时胡牌
- **判定**：牌墙只剩最后一张 → 摸到后胡牌
- **番数**：通常加1-2番

### 17. 天胡 / 地胡
- **定义**：
  - **天胡**：庄家起手14张直接胡牌
  - **地胡**：闲家起手第一巡摸牌后直接胡牌
- **番数**：通常满贯以上，极其罕见
- **出现玩法**：绝大多数玩法

## 三、地方特色牌型

### 四川麻将（血流成河）特色牌型

| 牌型 | 说明 |
|---|---|
| **清一色** | 同一花色，血流中常见高分方向 |
| **七对** | 七个对子，含龙七对变体 |
| **金钩钓** | 碰碰胡到只剩一张单吊 |
| **带幺** | 每组面子都含幺九牌 |
| **将对** | 所有牌都是2、5、8 |
| **杠上花** | 杠后补牌胡 |
| **查叫** | 结束后未听牌需赔分 |
| **查花猪** | 结束时仍持有定缺花色需赔分 |

### 武汉麻将（红中）特色牌型

| 牌型 | 说明 |
|---|---|
| **红中癞子** | 红中可代替任意牌 |
| **碰碰胡** | 全刻子，武汉常见高分 |
| **清一色** | 单花色，红中按桌规决定是否参与 |
| **硬胡** | 不用癞子（红中）胡牌 |
| **软胡** | 用了癞子（红中）胡牌，分数低于硬胡 |
| **开口** | 必须吃/碰/杠后才能胡牌 |
| **杠上开** | 杠后补牌胡 |

## 四、快速判断牌型的方法

### 判断流程
1. **数牌数**：14张？→ 正常；13张？→ 听牌中
2. **看花色**：只有一种花色？→ 可能是清一色；两种花色？→ 可能是混一色
3. **看结构**：全是刻子？→ 碰碰胡；全是顺子？→ 平和
4. **看字牌**：有三元牌刻子？→ 大/小三元；有四风刻子？→ 大/小四喜
5. **看特殊牌**：全是对子？→ 七对；有红中？→ 武汉麻将癞子；有财神？→ 杭州麻将

### 一句话总结常见牌型
- "全是同一花色" → 清一色
- "全是三张一样的" → 碰碰胡（对对胡）
- "全是两张一对" → 七对
- "什么幺九都有" → 十三幺
- "中发白全齐了" → 大三元
- "东南西北全齐了" → 大四喜
- "杠了补牌就胡" → 杠上开花
- "摸最后一张胡了" → 海底捞月
- "起手就胡" → 天胡（庄家）/ 地胡（闲家）
