# 麻将计分器 —— 小程序使用指南与 FAQ

> 本文档供微信AI知识库使用，帮助用户了解"麻将计分器"小程序的功能和使用方法。

## 小程序简介

**麻将计分器**是一款微信小程序，专为朋友线下聚会打牌设计。支持麻将、扑克等多种牌局计分，实时排名、战绩海报生成与分享。

### 核心功能

1. **灵活计分**：支持2~8人局，快捷加减分按钮 + 自定义分值输入
2. **台费管理**：独立台费统计，不混入玩家分数
3. **回合记录**：每轮加减分自动记录，随时回看
4. **排名结算**：自动排名，🥇🥈🥉奖牌展示
5. **战绩海报**：Canvas绘制精美战绩图，支持保存相册和分享好友
6. **玩法教学**：内置掼蛋、斗地主、德州扑克、四川血流、武汉红中、杭州麻将6种玩法规则
7. **历史记录**：最多保存100条历史对局，可随时查看和删除

## 使用教程

### 第一步：开局设置
1. 打开小程序，进入"计分"Tab
2. 选择玩家人数（2~8人），点击快捷按钮或使用+/-调整
3. 为每位玩家自定义昵称（不填则使用系统默认昵称）
4. 根据需要开启"台费"功能
5. 点击"开始计分"

### 第二步：记录分数
1. 在记分板页面，点击选中当前得分的玩家（高亮显示）
2. 使用快捷按钮加分或减分（+1~+20，-1~-20）
3. 也可以输入自定义分值
4. 如果有台费，在台费区域独立记录
5. 点击"下一回合"进入新回合

### 第三步：查看结果
1. 牌局结束后点击"结束计分"
2. 查看最终排名和每轮得分详情
3. 点击"预览战绩图"生成精美海报
4. 点击"保存战绩图"保存到手机相册
5. 或直接"分享"给微信好友

### 第四步：查看历史
1. 进入"我的"Tab
2. 在历史记录中查看过往对局
3. 点击可查看详细结果
4. 长按或点击删除图标可删除记录

## 常见问题 FAQ

**Q: 最多支持几个人计分？**
A: 最多支持8人同时计分，最少2人。

**Q: 台费是什么？**
A: 台费是独立于玩家分数的费用统计，比如包间费、茶水费等。启用后台费单独计算，不影响玩家排名。

**Q: 可以中途修改玩家名字吗？**
A: 开局后无法修改，建议开局前确认好每位玩家的昵称。

**Q: 历史记录能保存多少条？**
A: 最多保存100条，超出后最早的记录会被自动清除。

**Q: 数据保存在哪里？**
A: 所有计分数据保存在手机本地存储中，无需联网。删除小程序会丢失数据，请谨慎操作。

**Q: 战绩海报包含哪些内容？**
A: 包含本局赢家名字和分数、最终排名、每轮得分明细、日期、统计信息，以及小程序二维码。

**Q: 支持哪些地方的麻将规则计分？**
A: 计分器是通用的加减分工具，不绑定特定地方规则。你可以根据自己玩的规则自由加减分。玩法教学则提供了四川、武汉、杭州等常见地方规则参考。

**Q: 如何恢复默认头像和昵称？**
A: 在"我的"页面，点击"恢复默认资料"即可重置为系统分配的默认头像和昵称。

**Q: 小程序需要登录吗？**
A: 计分功能不需要登录，可直接使用。登录后可同步微信头像和昵称，支持手机号绑定。

**Q: 如何使用大牌分享功能？**
A: 在"分享"Tab中（如已更新），可以拍照或上传牌局照片，选择牌型后生成精美分享海报。
